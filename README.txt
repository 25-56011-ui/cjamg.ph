CJAMG MULTI-PAGE WEBSITE

Files:
- index.html — Home page
- activity-finder.html — Interactive activity finder
- programs.html — Programs and investment information
- experience.html — Locations, debrief, toolkits, and event video links
- about.html — About CJAMG, Coach Jay, mission, vision, and values
- faqs.html — Frequently asked questions
- contact.html — Contact details and inquiry form

HOW TO USE
1. Keep all seven HTML files in this same folder.
2. Open index.html in a browser to view the site.
3. Keep the images folder alongside the HTML files. Add the actual photos using these filenames when available: owner.jpg, team-building.jpg, experience.jpg, bridge-belong.jpg, unwind-elevate.jpg, align-accelerate.jpg.
4. Replace client logo placeholders with approved client logos before publishing.
5. The inquiry form prepares an email in the visitor's email app; it does not send messages directly from the website.

All pages include the same navigation, a direct Home button, and a shared footer.
